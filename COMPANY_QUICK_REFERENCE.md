## 🚀 Quick Start (3 Steps)

### 1. Create Job Posting
```
Job Title: Backend Developer (Python)
Description: We need an experienced Python developer...
Skills: Python, Django, REST APIs
Etc...
```

### 2. Add Coding Challenge
```
Title: Python REST API Challenge
Language: Python
Difficulty: Intermediate
Time Limit: 60 seconds

Problem:
"Implement a function that validates an email and returns JSON response..."

Test Cases:
✓ Valid email → { success: true }
✓ Invalid email → { success: false }
✗ Missing input → { success: false } (hidden)
✗ Edge cases → Proper handling (hidden)
```

### 3. Publish & Review
- Job is live on job board
- Candidates take assessment
- You review code submissions

## 🎓 Difficulty Levels

Pick the level that matches your hiring needs:

| Level | Best For | Solve Time |
|-------|----------|-----------|
| **Beginner** | Internships, Entry-level | 5-15 min |
| **Junior** | Junior Developer roles | 15-30 min |
| **Intermediate** | Mid-level Developer roles | 30-60 min |
| **Advanced** | Senior Developer roles | 60+ min |

## 📝 Best Practices

### ✅ DO:
- Be clear in problem description
- Provide 2-3 visible test cases
- Include 1-2 hidden test cases
- Test challenge before publishing
- Match difficulty to role level

### ❌ DON'T:
- Make problem ambiguous
- Hide all test cases
- Use time limit too low
- Forget to test your challenge
- Mismatch difficulty to role

## ❓ Common Questions

**Q: Can candidates use Google/external resources?**
A: Yes, unless you restrict it. For critical roles, follow with live coding interview.

**Q: What if code times out?**
A: Timeout indicates inefficient algorithm or infinite loop. Good filtering signal.

**Q: How long does assessment take?**
A: Candidates spend 10-30 min on typical challenge, plus testing time.

**Q: Can we reuse challenges?**
A: Yes! Build a library of challenges for similar roles.

**Q: How do we prevent cheating?**
A: Combination of visible + hidden tests, code analysis, and follow-up interviews.
